    Qué demuestra este proyecto

    1. El backend Express expone datos JSON mediante endpoints HTTP.
    2. Este frontend independiente llama a esos endpoints con fetch().
    3. Los datos recibidos se transforman en interfaz visual: estado, versión y tabla de usuarios.
    4. Si apagas la API, el panel muestra un error de conexión.
