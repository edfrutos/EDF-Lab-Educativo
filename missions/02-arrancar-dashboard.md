# Misión 02: arrancar el dashboard

## Objetivo

Servir el frontend estático y abrirlo en el navegador.

## Pasos

```bash
cd dashboard
python3 -m http.server 5173
```

Abre:

```txt
http://localhost:5173
```

## Resultado esperado

Verás un panel web con el estado de la API y la tabla de usuarios.

## Reto extra

Apaga la API y recarga el dashboard para ver el estado de error.
