# Project Research Summary — v1.5

**Project:** EDF Lab Educativo  
**Domain:** Educational full-stack lab (Express + static/framework frontends)  
**Researched:** 2026-06-10  
**Confidence:** HIGH

## Executive Summary

v1.5 should teach **authentication and production awareness** without breaking the beginner path. The API gains an **optional** JWT layer (`AUTH_ENABLED=false` by default); the vanilla dashboard gains a **login flow** when auth is on. A second track documents **secrets, environment variables, and deployment checklists** — concepts, not a full cloud deploy.

Stack changes are **additive**: one runtime dependency (`jsonwebtoken`) and one dev-oriented dependency (`bcryptjs` for password comparison teaching). React/Vue dashboards stay **out of scope** for login parity (reto extra in Mission 14).

## Key Findings

### Recommended approach

| Area | Decision | Rationale |
|------|----------|-----------|
| Auth model | Bearer JWT | Industry-standard; visible in Network tab; pairs with Mission 14 |
| Default mode | `AUTH_ENABLED=false` | Missions 01–13 and open CRUD keep working unchanged |
| Credentials | Single admin from env (`AUTH_USER`, `AUTH_PASSWORD`) | Simple lab; doc explains hashing for production |
| Protected routes | `/users` CRUD when auth on | `GET /health` and `GET /` stay public (monitoring + discovery) |
| Token storage | `sessionStorage` in vanilla dashboard | Teaches tab-scoped session vs `localStorage` |
| Framework UIs | Reto extra only | Vanilla remains primary; avoids tripling auth UI work |

### Expected deliverables

**Must have:** `POST /auth/login`, auth middleware, 401 handling, vanilla login/logout, tests, `docs/17-autenticacion.md`, `docs/18-despliegue.md`, Mission 14, `.env.example`, NOTEBOOK entries  
**Should have:** OpenAPI `securitySchemes`, Compose `env_file` pattern, production checklist  
**Defer:** OAuth2/OIDC, refresh tokens, RBAC, framework login parity, real TLS termination, K8s

### Critical pitfalls

1. **Breaking existing learners** — forgetting `AUTH_ENABLED` default `false`
2. **CORS + Authorization** — must allow `Authorization` header; document preflight
3. **Teaching security theater** — document clearly that lab secrets are not production-grade
4. **Scope creep** — production milestone is **guidance**, not hosting the app on AWS
