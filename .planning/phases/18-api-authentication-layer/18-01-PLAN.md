<task type="auto">
  <name>Task 2: Implement api/auth.js and POST /auth/login</name>
  <read_first>18-CONTEXT.md D-03–D-11, D-08, 18-PATTERNS.md excerpts</read_first>
  <files>api/auth.js, api/index.js</files>
  <action>
    Create `api/auth.js` exporting:

    - `isAuthEnabled()` — `process.env.AUTH_ENABLED === 'true'`
    - `validateAuthConfig()` — if enabled, require `JWT_SECRET`, `AUTH_USER`, `AUTH_PASSWORD`; throw Error with Spanish message listing missing vars (used in plan 18-02 startup)
    - `signToken(username)` — jwt.sign `{ sub: username }`, `expiresIn: '1h'`, secret from env
    - `verifyToken(token)` — jwt.verify or rethrow
    - `loginHandler(req, res)`:
      - If !isAuthEnabled() → 404 `{ error: 'La autenticación no está activada (AUTH_ENABLED=false).' }`
      - Validate username/password strings non-empty → 400 Spanish error
      - Compare to env → 401 `{ error: 'Credenciales incorrectas.' }` on mismatch
      - Success → 200 `{ token, expiresIn: 3600 }`

    In `api/index.js`:
    - `const auth = require('./auth');`
    - `app.post('/auth/login', auth.loginHandler);`
    - Do NOT add requireAuth to /users yet (plan 18-02).
    - Optionally add stub `requireAuth` that only calls next() — or wait for 18-02.

    Export `signToken` for tests (D-02).
  </action>
