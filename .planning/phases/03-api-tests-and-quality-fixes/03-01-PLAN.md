## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process.env → DATA_FILE_PATH | Variable de entorno inyectada por el proceso padre (tests o shell). Solo controla una ruta de archivo local — no hay superficie de red. |
| URL params → parseUserId | Entrada no confiable del cliente HTTP. Después del fix, qualquier string no entero positivo devuelve null → 400. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | parseUserId / GET|PUT|DELETE /users/:id | mitigate | Fix D-06: `Number(value)` + `Number.isInteger(id) && id > 0` rechaza `1abc`, `0`, strings. Implementado en Task 2. |

</threat_model>
