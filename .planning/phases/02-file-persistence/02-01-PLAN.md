CAMBIO 4 — Añadir los tres helpers asíncronos después de validateUserPayload() y antes de los Routes:
```javascript
// ─── Persistencia ────────────────────────────────────────────────────────────

async function saveUsersData(data) {
  await mkdir(DATA_DIR, { recursive: true });
  await writeFile(DATA_FILE, JSON.stringify(data, null, 2), 'utf8');
}

async function loadUsers() {
  try {
    const raw  = await readFile(DATA_FILE, 'utf8');
    const data = JSON.parse(raw);
    users      = data.users;
    nextUserId = data.nextId;
  } catch (err) {
    if (err instanceof SyntaxError) {
      console.warn('[warn] data/users.json corrupto — restaurando semilla');
      await saveUsersData(SEED_DATA);
    } else if (err.code === 'ENOENT') {
      console.info('[info] data/users.json no encontrado — creando con semilla');
      await saveUsersData(SEED_DATA);
    } else {
      console.error('[error] No se pudo leer data/users.json:', err.message);
    }
    users      = [...SEED_DATA.users];
    nextUserId = SEED_DATA.nextId;
  }
}

async function saveUsers() {
  await saveUsersData({ users, nextId: nextUserId });
}
```

IMPORTANTE — copia por valor de semilla: `users = [...SEED_DATA.users]`, NO `users = SEED_DATA.users` (Pitfall 5 de RESEARCH.md — asignación por referencia corrompe SEED_DATA en siguientes recuperaciones).

// ELIMINAR:

module.exports = app;

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | api/data/users.json | accept | Archivo de demo local con datos inventados (no hay PII real). El laboratorio es local; no hay acceso externo. writeFile sobrescribe el archivo completo en cada operación, no hay escrituras parciales acumulativas. |

| T-02-01-04 | Denial of Service | startServer() — fallo no recuperable en loadUsers | mitigate | startServer().catch() llama a process.exit(1) con log de error. Fallo visible, no silencioso. |
