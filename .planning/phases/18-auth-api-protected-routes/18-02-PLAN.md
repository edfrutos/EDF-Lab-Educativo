  <action>
    Create `api/auth.js` with:

    **Config helpers:**
    - `getJwtSecret()` — `process.env.JWT_SECRET` or dev default `'dev-only-change-in-production'` + `console.warn` if missing
    - `getCookieOptions()` — name `edf_session`, httpOnly, sameSite `lax`, secure if `NODE_ENV===production`, maxAge from JWT expiry

    **JWT:** sign payload `{ sub: accountId, email }`, `expiresIn: process.env.JWT_EXPIRES_IN || '24h'`

    **Middleware `requireAuth(req, res, next)`:**
    - If `process.env.AUTH_DISABLED === '1'` → `next()` (test bypass)
    - Else read token from `req.cookies.edf_session`, verify JWT
    - Invalid/missing → `401` `{ error: 'Sesión no válida o expirada. Inicia sesión.' }`

    **Handlers:**
    - `loginHandler` — validate body `{ email, password }` strings; lookup account via backend `findAccountByEmail` (require sqlite or pg based on `DATABASE_URL` same as db.js); bcrypt.compare; on fail **403** `{ error: 'Credenciales inválidas' }`; on success set cookie + **200** `{ message: 'Sesión iniciada', email }`
    - `logoutHandler` — clear cookie + **200** `{ message: 'Sesión cerrada' }`

    Export: `requireAuth`, `loginHandler`, `logoutHandler`, `COOKIE_NAME = 'edf_session'`

    Keep file readable with short Spanish comments for learners.
  </action>
  <verify>
    <automated>node --check api/auth.js</automated>
  </verify>
  <acceptance_criteria>
    - auth.js passes syntax check
    - Exports requireAuth and both handlers
    - No password or hash logged on failure
  </acceptance_criteria>
  <done>Auth module complete</done>
