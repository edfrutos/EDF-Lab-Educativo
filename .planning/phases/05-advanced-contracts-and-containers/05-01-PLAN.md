info:

**Paths — cubrir los 9 endpoints en este orden:**
1. `GET /` — responde `{ message, version, endpoints[] }`. Response 200, content application/json, schema inline con los tres campos.
2. `GET /health` — responde `{ status: "healthy", timestamp: ISO8601 }`. Response 200 con schema inline.
3. `GET /users` — responde array de User (ref). Response 200 con schema `type: array, items: $ref User`.
4. `POST /users` — requestBody required con `$ref UserInput`. Responses: 201 User, 400 Error (dos variantes de mensaje), 500 Error.
5. `GET /users/{id}` — parameter `id` in: path, required: true, schema type: integer. Responses: 200 User, 400 Error, 404 Error.
6. `PUT /users/{id}` — parameter `id` + requestBody `$ref UserInput`. Responses: 200 User, 400 Error, 404 Error, 500 Error.
7. `DELETE /users/{id}` — parameter `id`. Response 200 con schema `{ message: string, user: $ref User }`, 400 Error, 404 Error, 500 Error.
8. `GET /about` — responde `{ name, description, frontend, backend }`. Schema inline.
9. `GET /time` — responde `{ now: ISO8601 }`. Schema inline.

**components/schemas — tres schemas reutilizables:**
- `User`: type object, required [id, name, email], properties: id (integer, example: 1), name (string, example: "John Doe"), email (string, example: "john@example.com")
- `UserInput`: type object, required [name, email], properties: name (string, example: "Carlos López"), email (string, example: "carlos@example.com")
- `Error`: type object, properties: error (string, example: "Usuario no encontrado.")

**Reglas de mensajes de error — copiar LITERALMENTE de index.js:**
- 400 en rutas con :id → example: `El parámetro ":id" debe ser un número entero.`

- 400 en POST/PUT (name vacío) → example: `El campo "name" es obligatorio y debe ser texto.`
- 400 en POST/PUT (email vacío) → example: `El campo "email" es obligatorio y debe ser texto.`
- 500 → example: `No se pudo persistir el cambio. Comprueba los permisos del archivo.`
- 200 DELETE → example en message: `Usuario eliminado correctamente.`

**Reglas de formato YAML:**
- Indentación: 2 espacios consistentes. NUNCA tabs.
