## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dashboard client -> auth API | entrada no confiable al iniciar OAuth; no debe saltarse contrato server-side |
| callback -> sesión cookie | el cliente solo consume resultado; validación de `state` queda en backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-41-01 | T | `dashboard/app.js` handoff OAuth | mitigate | Consumir exclusivamente `/auth/oauth/start` y usar `authUrl` devuelta; no construir callback manual |
| T-41-02 | I | Mensajes de error auth en UI | mitigate | Reutilizar canal existente de errores auth sin exponer tokens ni secretos |
| T-41-03 | D | Regresión del flujo clásico | mitigate | Mantener tests smoke clásicos y OAuth en el mismo suite de continuidad |
</threat_model>
