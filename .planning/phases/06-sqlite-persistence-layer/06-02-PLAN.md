    Rewrite all five user route handlers to use db.js async helpers (D-11 contract lock):

    **GET /users:** `async (req, res) => { res.json(await getAllUsers()); }`

    **GET /users/:id:** parseUserId → 400 if null → `getUserById` → 404 if undefined → json user

    **POST /users:** validateUserPayload → 400 → try `createUser(name, email)` → 201 json user. Catch: log `[error] createUser() falló en POST /users:` → 500 with exact string `'No se pudo persistir el cambio. Comprueba los permisos del archivo.'` (D-11 — keep verbatim despite DB store)

    **PUT /users/:id:** parseUserId → validate → `getUserById` → 404 if missing → try `updateUser` → json user. Catch: log with `updateUser()` → same 500 string

    **DELETE /users/:id:** parseUserId → try `deleteUser` → 404 if null → json `{ message: 'Usuario eliminado correctamente.', user: deletedUser }`. Catch: log with `deleteUser()` → same 500 string

    D-12 adaptation: no in-memory rollback needed — DB is single source of truth; failed writes return 500 via catch.

    All routes that call db must be `async`.
  </action>
