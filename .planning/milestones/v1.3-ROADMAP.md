# Milestone v1.3: PostgreSQL Persistence

**Status:** ✅ SHIPPED 2026-06-01

**Total Plans:** 8

## Overview

Teach the evolution from SQLite to PostgreSQL as a client-server database while keeping the backend → JSON → dashboard flow intact. Postgres is additive: host `npm start` without `DATABASE_URL` still uses SQLite.

## Milestone Summary

**Key accomplishments:**

1. Dual persistence: `db.js` routes to SQLite or Postgres via `DATABASE_URL`
2. Three-service Compose stack with `postgres_data` named volume and healthcheck
3. Shared seed/migration path into empty Postgres (`api/seed.js`)
4. 32 automated tests (16 SQLite + 16 Postgres on isolated `edf_lab_test`)
5. `docs/15-postgresql.md`, Mission 12, updated doc 14 and NOTEBOOK

**Key decisions:**

- Raw SQL + `pg` Pool (no ORM)
- SQLite remains host-dev default without env var
- Compose runtime uses Postgres; bind mount keeps `users.json` for seed only
- Mission 11 retained; Mission 12 is Postgres + `psql` path
