# Milestone v2.4: OAuth Foundation

**Status:** ✅ SHIPPED 2026-06-17  
**Phases:** 40–41  
**Total Plans:** 4  
**Tag:** `v2.4`

## Overview

Contrato OAuth mock en backend y recorrido visible desde el dashboard vanilla, sin romper login clásico, refresh rotation ni el contrato CRUD protegido.

## Phases

### Phase 40: OAuth social login foundation

**Goal:** El operador puede iniciar un flujo OAuth/social de forma controlada y didáctica sin romper el contrato auth vigente.  
**Depends on:** Phase 39  
**Requirements:** AUTH-ADV-01  
**Plans:** 2/2 complete

- Backend: `GET /auth/oauth/start`, `GET /auth/oauth/callback`, validación `state` anti-CSRF, sesión compatible
- Docs/misiones/NOTEBOOK: contrato OAuth mock y fricción `state` inválido

### Phase 41: OAuth dashboard integration foundation

**Goal:** El alumno/operador puede activar el flujo OAuth mock desde el dashboard y completar un recorrido auth visible sin romper login clásico ni contratos backend existentes.  
**Depends on:** Phase 40  
**Requirements:** AUTH-ADV-01  
**Plans:** 2/2 complete

- Dashboard: botón «Continuar con OAuth mock», handoff con `fetch` + `credentials: 'include'`
- E2E: `runOAuthMockSmokeFlow` en `auth-smoke.vanilla.spec.js`
- Docs/misiones/NOTEBOOK: login clásico vs OAuth mock; fricción redirección al JSON del callback

## Milestone Summary

**Key accomplishments:**

1. Contrato OAuth mock backend (start/callback) con cookie `edf_oauth_state` y tests SQLite
2. OAuth mock accesible desde UI vanilla con continuidad auth y sin regresión del flujo clásico
3. Documentación y misiones distinguen login clásico vs OAuth mock
4. CORS por defecto acepta `localhost` y `127.0.0.1` en puertos 5173–5175

**Issues resolved during milestone:**

- Callback OAuth consumido con `fetch` en lugar de `window.location` (evita página JSON en `:3100`)
- Origen `127.0.0.1` rechazado por whitelist CORS estricta

**Issues deferred (post-v2.4):**

- Proveedores OAuth reales (Google/GitHub)
- Account linking password ↔ social
- OAuth en dashboards React/Vue (solo vanilla en v2.4)
