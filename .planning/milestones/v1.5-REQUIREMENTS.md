# Requirements: EDF Lab Educativo

**Defined:** 2026-06-01
**Core Value:** Make the backend -> JSON -> frontend flow visible, executable, and teachable, turning real errors into documented learning.

## v1.5 Requirements

Requirements for **Production Auth & Deployment**. Phases 18–21.

### Authentication (API)

- [x] **AUTH-01**: `accounts` table (email UNIQUE, password_hash) exists in SQLite and PostgreSQL schemas.
- [x] **AUTH-02**: Empty database seeds one operator account from `ADMIN_EMAIL` / `ADMIN_PASSWORD` env vars.
- [x] **AUTH-03**: `POST /auth/login` validates credentials with bcrypt and sets httpOnly session cookie (JWT).
- [x] **AUTH-04**: `POST /auth/logout` clears the session cookie.
- [x] **AUTH-05**: All `/users` routes require authentication; return 401 with JSON error when missing/invalid.
- [x] **AUTH-06**: `GET /health` and `GET /` remain public (no auth required).
- [x] **AUTH-07**: CORS allows credentials and explicit origins for ports 5173, 5174, 5175.

### Authentication (Tests & Dev)

- [x] **AUTH-08**: API tests pass using documented test-only bypass (`AUTH_DISABLED=1`) plus new tests for 401/200 auth paths.
- [x] **AUTH-09**: OpenAPI spec documents `/auth/login`, `/auth/logout`, and cookie/bearer security for protected routes.

### Authentication (Dashboard)

- [x] **AUTH-10**: Vanilla dashboard has login form and logout control; stores session via httpOnly cookie (`credentials: 'include'`).
- [x] **AUTH-11**: Dashboard handles 401 by showing Spanish guidance and prompting login (consistent with existing error UX).
- [x] **AUTH-12**: README or auth doc notes React/Vue optional apps need the same `credentials: 'include'` pattern.

### Deployment & Secrets

- [x] **DEPLOY-01**: `api/.env.example` lists all required secrets with comments.
- [x] **DEPLOY-02**: `.env` is gitignored; Compose uses `env_file` for API (no secrets baked into images).
- [x] **DEPLOY-03**: API refuses to start in production mode without `JWT_SECRET` (fail-fast lesson).
- [x] **DEPLOY-04**: Documentation explains TLS termination at reverse proxy (nginx) vs Node.

### Learning Documentation

- [x] **DOCS-01**: `docs/17-autenticacion.md` explains passwords, JWT, cookies, CORS credentials, and protected fetch.
- [x] **DOCS-02**: Mission 14 guides login, protected CRUD, logout, and inspecting auth cookies in DevTools.
- [x] **DOCS-03**: `docs/00-indice.md` and `README.md` updated; auth path marked **advanced** after frameworks.
- [x] **DOCS-04**: Real auth/CORS/deploy errors recorded in `NOTEBOOK.md`.
