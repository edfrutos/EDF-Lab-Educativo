## Milestone Summary

**Key accomplishments:**

1. JWT session in httpOnly cookie `edf_session`; bcrypt operator accounts; `/users` protected
2. Vanilla dashboard login gate + logout; React/Vue `credentials: 'include'` documented
3. Production fail-fast without `JWT_SECRET`; Compose loads `api/.env` via `env_file`
4. `docs/17-autenticacion.md`, `docs/18-production-deploy.md`, Mission 14
5. Advanced v1.5 learning path in index/README; NOTEBOOK auth/deploy errors; 46-test suite with auth block

**Key decisions:**

- JWT in httpOnly cookie (not localStorage)
- `accounts` table separate from CRUD `users`
- `AUTH_DISABLED=1` test-only bypass for CRUD suites
- CORS `credentials: true` + explicit origins (5173–5175)
- git-secrets compatibility: JWT documented via comments in tracked templates
