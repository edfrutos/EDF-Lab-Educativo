# Milestone v1.5: Authentication & Production Readiness

**Status:** ✅ SHIPPED 2026-06-20  
**Phases:** 18–20  
**Estimated plans:** 8

## Overview

Teach **who can call the API** (authentication) and **what changes when leaving localhost** (secrets, env vars, deployment checklist). The beginner path stays intact: with `AUTH_ENABLED=false` (default), the lab behaves exactly as in v1.4.

When auth is enabled, learners log in through the **vanilla dashboard**, receive a JWT, and send `Authorization: Bearer <token>` on user CRUD calls. Framework dashboards (React/Vue) remain optional; Mission 14 includes a **reto extra** to port the pattern.

## Goals

1. Make JWT auth **visible and testable** in the API and vanilla UI.
2. Explain **401 vs 403**, public vs protected routes, and token storage tradeoffs.
3. Document **production hygiene**: `.env`, secrets, CORS tightening, TLS overview — without mandating a cloud deploy.

## Milestone Summary (target)

**Key deliverables:**

1. Optional JWT auth on API user routes (`AUTH_ENABLED`)
2. Vanilla dashboard login/logout with Bearer token in `sessionStorage`
3. `docs/17-autenticacion.md` + `docs/18-despliegue.md`
4. Mission 14 — login end-to-end + Network tab
5. `.env.example`, OpenAPI update, NOTEBOOK auth/deploy errors
6. Expanded test suite covering auth on/off paths

**Key decisions (proposed):**

- `jsonwebtoken` as the only new **runtime** dependency for JWT
- `AUTH_ENABLED=false` by default — beginner missions unchanged
- Single admin user from environment variables (lab-only; documented warnings)
- Protect `/users` CRUD only; keep `/health` and `/` public
- React/Vue login UI deferred to reto extra (not blocking v1.5 ship)

**Out of scope:**

| Item | Reason |
|------|--------|
| OAuth2 / social login | Beyond single-user lab scope |
| Refresh tokens / rotation | Advanced topic; mention in doc 18 as “siguiente paso” |
| RBAC / roles | Not needed for CRUD teaching |
| Full TLS setup in repo | Conceptual doc only |
| Kubernetes / PaaS deploy | Compose remains the orchestration ceiling |
| Mandatory auth always on | Would break missions 01–13 |
